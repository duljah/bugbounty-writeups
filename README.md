# 🐛 Bug Bounty Writeups

A collection of **sanitized educational writeups** of vulnerabilities discovered during authorized bug bounty testing.

> **⚠️ Important:** All writeups in this repository have been **sanitized** to remove:
> - Vendor / platform names
> - Account IDs and UIDs
> - Bounty amounts
> - Real user data
> - Program-specific details
>
> All vulnerabilities have been **fully remediated** by the affected parties. These writeups are published **after** receiving explicit permission and **after** remediation, in compliance with responsible disclosure policies.
